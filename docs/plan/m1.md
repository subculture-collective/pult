# Milestone 1 plan

M1 delivers a working `tender` for eight apps on Linux and macOS: catalog, 26-role palettes, apply, live reload, validation, rollback and ownership detection. Decisions are in [ADR 0002](../adr/0002-theme-tender-foundations.md); contracts are in [`docs/reference/`](../reference/).

## Apps

ghostty, kitty, alacritty, tmux, starship, lazygit, yazi, btop. Together they cover every integration method: `include`, `owned`, `keys` (TOML and YAML) and `ansi`.

## Acceptance criteria

1. Applying a catalog theme updates all eight apps on Arch and macOS, and each app's own validator passes.
2. Uninstall right after apply restores byte-identical originals. If a file was edited after apply, uninstall shows a diff and changes nothing without confirmation.
3. On Omarchy, the theme appears as an Omarchy theme and switches with `omarchy-theme-set`; no Omarchy-owned file is edited.
4. A stow symlink, a chezmoi-managed file, a matugen hook and a detected Hyprland framework each lead to a prompt or handoff, never a silent overwrite.
5. The catalog contains no `nonfree` scheme. Unknown-licence schemes are listed and download on first use.
6. Expanding Catppuccin's ANSI colors to 26 roles stays within the ΔE threshold set in work package 2: leave-one-out mean ΔE ≤ 0.020 and max ≤ 0.110 in OKLab; see the [catalog schema](../reference/catalog-schema.md#test-oracle-and-threshold).
7. Search filters by computed tags and returns similar themes for a chosen theme.
8. A bundle with a missing or wrong minisign signature is rejected, and the built-in bundle is used instead.

## Known risks

- **Editing TOML while keeping comments.** Go's common TOML libraries don't preserve comments on write. Package 6 starts with a short spike comparing a comment-preserving parser against targeted text edits at parser-reported positions.
- **Validator coverage.** Not every app has a config check command. Apps without one get a parse check by Theme Tender's own parser and are marked as such.
- **Aether template compatibility.** Unknown until Aether's template variable names are compared with ours (package 5).
- **Soyuz availability.** macOS results may arrive after merge. The release checklist requires a green macOS run before tagging.
