A universal remote for your colors

Pult is a terminal app that themes your other apps from one palette. It finds the apps you have, writes only their color settings, shows a dry run first, and pult uninstall puts every file back.

Colors, and nothing else

  1. Find what you have

    pult list

    Checks which of the 20 supported apps are installed and which tool, if any, owns each config file.

  2. Read the plan

    pult apply -dry-run catppuccin-mocha

    Prints every file it would touch and a diff for each. Nothing is written.

  3. Apply

    pult apply catppuccin-mocha

    Uses the app's include or theme mechanism where it has one, so your other settings stay as they are. Each file is recorded before it changes.

  4. Put it back

    pult uninstall

    Restores every changed file. If you edited a file after Pult wrote it, Pult leaves your edit alone unless you pass -force.

About 2,700 themes

From iTerm2 Color Schemes, Tinted Theming, Catppuccin, Dracula and Gogh. About 1,800 ship with their colors. The rest download when you apply them. Search by name or tag, list close matches, or bring your own palette as a JSON or TOML file.

Your other tools

Files managed by stow, chezmoi, matugen, wallust, pywal or a Hyprland framework are written only after you confirm. On Omarchy, Pult writes an Omarchy theme and switches to it instead of editing Omarchy's files.

Install

Pre-release. There are no packages yet, so for now you build it from source. You need Go 1.26 or newer and Git.

git clone https://git.subcult.tv/subculture-collective/pult.git
cd pult
make catalog
go build -o ~/.local/bin/pult ./cmd/pult
export PULT_CATALOG=$PWD/.cache/catalog.db.zst
pult tui

Add the PULT_CATALOG line to your shell profile to keep it. More in the docs.
