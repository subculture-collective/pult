Docs

Pult (pult) is a terminal app that themes your other apps from one palette. It runs on Linux and macOS. It is early software, so expect changes between 0.x releases.

Install

Arch Linux

Pult is in the subcult pacman repository on git.subcult.tv. Gitea signs it with its own key.

curl -fsS https://git.subcult.tv/api/packages/subculture-collective/arch/repository.key | sudo pacman-key --add -
sudo pacman-key --lsign-key CCE8B0F3BCDD601D909773E4466AA6E8241453D2
printf '\n[subcult]\nSigLevel = Required\nServer = https://git.subcult.tv/api/packages/subculture-collective/arch/$repo/$arch\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Sy pult

Tarball

Download the Linux or macOS tarball for your machine from the releases page, unpack it and put pult on your PATH. The catalog is built in.

From source

You need Go 1.26 or newer, Git and network access.

git clone https://git.subcult.tv/subculture-collective/pult.git
cd pult
make catalog
go build -o ~/.local/bin/pult ./cmd/pult
export PULT_CATALOG=$PWD/.cache/catalog.db.zst

make catalog fetches the pinned theme sources and builds .cache/catalog.db.zst. A source build has no catalog of its own, so Pult needs PULT_CATALOG to find this file. Add the export to your shell profile, with the full path to your checkout. Make sure ~/.local/bin is on your PATH.

First run

$ pult list                             # which apps Pult found
$ pult search -tag pastel rose          # find a theme
$ pult apply -dry-run catppuccin-mocha  # see the plan and diffs
$ pult apply catppuccin-mocha           # asks, then applies
$ pult uninstall                        # put every changed file back

Or run pult tui and do all of that from one screen.

The TUI

pult tui opens full screen with two tabs, themes and apps. The themes tab has a search box, the tags, the theme list and a preview of the selected theme's colours. A ↓ beside a theme means its colours aren't bundled and are downloaded when you apply it. The apps tab lists the supported apps with the details of the selected one. Press ? in the TUI for this list.

KeyAction
[ ]Switch between themes and apps
tabMove to the next pane: search, tags, themes
j k or arrowsMove through the list; pgup pgdn page, g G jump to the first or last
/Search by name, family or author; enter or esc leaves the search box
1–9Toggle a tag: dark, light, pastel, neon, muted, warm, cool, high-contrast, low-contrast. In the tags pane, arrows move and space toggles.
sList the themes closest to the selected one
escGo back from the closest-themes list
enterShow the plan for the selected theme and ask y/N
uRoll back the last apply, after y/N
?Show the keys
qQuit

The mouse works too. Click a tab, a pane, a tag or a row. Click the selected theme again to see its plan, then click Apply or Cancel. The wheel scrolls lists and dialogs.

The TUI leaves files other tools own alone. Use pult apply when you want to be asked about those.

Commands

CommandWhat it does
search [words]Find themes. -tag t (repeatable) requires a tag, -similar id lists the closest themes, -n 20 caps the results.
apply [theme]Theme every supported app. The theme is a catalog ID or a palette file. -dry-run prints the plan and diffs and changes nothing. -yes skips the final confirmation, though files other tools own are still asked about. -profile p uses a profile.
uninstallPut every changed file back. -yes skips the confirmation. -force also restores files edited since Pult wrote them.
tuiBrowse, preview, apply and undo in the terminal.
listShow supported apps and their state.
doctorCheck for interrupted runs, app upgrades, Omarchy and frameworks. -recover rolls back interrupted runs.
palette <theme>Print the resolved palette and change nothing. -format json or toml.
render <theme> <template>Render one Mustache template and apply nothing. -o file writes to a file and overwrites it without a backup. -aether reads Aether's {name} placeholders.
profilesList profiles in $XDG_CONFIG_HOME/pult/profiles.
updateInstall the newest signed data bundle. Skip this for now.
versionPrint the version.

Finding themes

The catalog holds about 2,700 themes from iTerm2 Color Schemes, Tinted Theming, Catppuccin, Dracula and Gogh. About 1,800 ship with their colors. The others are listed by name and marked (downloaded on first use). Each theme keeps its own licence.

$ pult search rose -tag pastel -n 5
$ pult search -similar catppuccin-mocha
$ pult search -tag light -tag warm

Profiles

A profile is a TOML file that picks a theme, a set of apps and a terminal font. Keep profiles in $XDG_CONFIG_HOME/pult/profiles/, or pass any path.

schema = 1
theme = "nord"
apps = ["kitty", "bat"]

[font]
family = "JetBrains Mono"
size = 12
$ pult apply -profile desk          # profiles/desk.toml
$ pult apply -profile ./work.toml   # any file
$ pult apply -profile desk dracula  # the profile, with another theme
FieldMeaning
themeCatalog ID, or a palette file path relative to the profile.
appsRegistry IDs to theme. Left out or empty means every app.
skipRegistry IDs to leave alone, even if apps lists them.
[font]family and optional size in points, for kitty, Ghostty, Alacritty and foot.

Unknown fields are an error, so a typo doesn't pass unnoticed. Pult never installs fonts. On Linux it warns when fc-list doesn't know the family.

Palette files

A palette file is what pult palette prints, in JSON or TOML. It works anywhere a theme ID does. An argument counts as a file when it contains / or ends in .json or .toml.

{
  "schema": 1,
  "theme": {"name": "My Theme", "appearance": "dark"},
  "colors": {
    "ansi0": "#100b19", ... through ... "ansi15": "#f0ece4",
    "background": "#100b19",
    "foreground": "#f0ece4"
  }
}

colors needs ansi0 through ansi15, background and foreground. Pult derives any other role. The theme block is optional.

Palette export

pult palette and pult render hand a theme's colors to other tools without applying anything and without touching the change record.

$ pult palette -format toml catppuccin-mocha
$ pult render catppuccin-mocha my.conf.mustache
$ pult render -o out.conf catppuccin-mocha kitty/pult.conf.mustache

The template is a file path or the name of a bundled template. See the palette export reference and the template variables.

What gets changed

Pult changes colors and, when a profile asks, the terminal font. It uses each app's own include or theme mechanism where one exists, so your other settings aren't touched. For kitty, it adds one line to kitty.conf and writes colors to a separate file:

 font_size 12
+include pult.conf

Run pult apply -dry-run to see the exact plan and diffs for your machine. If an app rejects its new config during validation, Pult restores that app's files and reports it.

Other tools

Each config file has one owner. Pult works out which and acts on that.

OwnerWhat Pult does
NobodyWrites the file.
stow, chezmoi or another symlinkAsks first. Writing through stow changes your dotfiles repository.
matugen, wallust, pywalAsks first.
Hyprland frameworkAsks first. Noctalia, DankMaterialShell, HyDE, Caelestia and end-4 are switched through their own commands. ML4W regenerates colors from the wallpaper, so it has no backend.
OmarchyWrites an Omarchy theme, ~/.config/omarchy/themes/pult-<slug>/, and switches to it. Omarchy's own files are never edited.
Subarchy defaultsLeaves them alone.

Framework limits are in the framework reference.

Undo and recovery

Every file Pult creates, edits or deletes is recorded before it is touched, with a compressed copy of the original under $XDG_STATE_HOME/pult/. The format is documented, so you can restore a file by hand even if Pult itself is broken.

  • pult uninstall restores every changed file and removes the ones Pult created.
  • A file you edited after Pult wrote it is left as it is, and Pult shows the difference. pult uninstall -force restores it anyway.
  • u in the TUI rolls back the last apply.
  • pult doctor reports interrupted runs. pult doctor -recover rolls them back.
